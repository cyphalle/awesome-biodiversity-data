## Global Biodiversity Databases

- [GBIF](https://www.gbif.org/) - Global Biodiversity Information Facility. The largest biodiversity database with 2B+ occurrence records.
- [OBIS](https://obis.org/) - Ocean Biodiversity Information System. Marine biodiversity data from all oceans.
- [iNaturalist](https://www.inaturalist.org/) - Citizen science platform with 150M+ observations.
- [eBird](https://ebird.org/) - Global bird observation database by Cornell Lab.
- [BIEN](https://bien.nceas.ucsb.edu/bien/) - Botanical Information and Ecology Network.

## Species Data

### Conservation Status
- [IUCN Red List](https://www.iucnredlist.org/) - Global standard for species extinction risk assessment.
- [CITES Species+](https://speciesplus.net/) - Database on species protected by CITES and CMS.
- [NatureServe Explorer](https://explorer.natureserve.org/) - Conservation status for species in the Americas.

### Taxonomy & Traits
- [Catalogue of Life](https://www.catalogueoflife.org/) - Global species checklist with 2M+ species.
- [ITIS](https://www.itis.gov/) - Integrated Taxonomic Information System.
- [TRY Plant Trait Database](https://www.try-db.org/) - Plant functional traits.
- [AnAge](https://genomics.senescence.info/species/) - Animal ageing and longevity database.
- [FishBase](https://www.fishbase.org/) - Global database of fish species.
- [AmphibiaWeb](https://amphibiaweb.org/) - Amphibian biology and conservation.

## Protected Areas

- [World Database on Protected Areas (WDPA)](https://www.protectedplanet.net/) - Most comprehensive global database of protected areas.
- [Natura 2000](https://natura2000.eea.europa.eu/) - EU network of nature protection areas.
- [Key Biodiversity Areas (KBAs)](https://www.keybiodiversityareas.org/) - Sites contributing significantly to global biodiversity persistence.
- [Important Bird Areas (IBAs)](https://www.birdlife.org/what-we-do/conservation-science/important-bird-and-biodiversity-areas-ibas/) - BirdLife International's IBA network.

## Ecosystem Services

- [ENCORE](https://encore.naturalcapital.finance/) - Natural Capital Finance Alliance tool for nature-related risks.
- [InVEST](https://naturalcapitalproject.stanford.edu/software/invest) - Stanford's ecosystem services modeling suite.
- [ARIES](https://aries.integratedmodelling.org/) - AI-powered ecosystem services assessment.
- [Co$ting Nature](https://www.policysupport.org/costingnature) - Natural capital accounting tool.

## APIs & Tools

### Data Access APIs
- [GBIF API](https://www.gbif.org/developer/summary) - Access to all GBIF occurrence and species data.
- [IUCN Red List API](https://apiv3.iucnredlist.org/) - Programmatic access to Red List assessments.
- [Species+/CITES API](https://api.speciesplus.net/) - Access to CITES trade data.
- [iNaturalist API](https://api.inaturalist.org/v1/docs/) - Access to citizen science observations.
- [eBird API](https://documenter.getpostman.com/view/664302/S1ENwy59) - Bird observation data API.

### Geospatial Tools
- [Google Earth Engine](https://earthengine.google.com/) - Planetary-scale geospatial analysis.
- [Copernicus Land Monitoring](https://land.copernicus.eu/) - EU land monitoring datasets.
- [Global Forest Watch](https://www.globalforestwatch.org/) - Forest monitoring platform.
- [MapBiomas](https://mapbiomas.org/) - Land use mapping for South America.
- [KoreAves](https://koreaves.com/) - Free English-first reference atlas for South Korean birds, connecting checklist taxa to sourced regional occurrence records without treating record counts as abundance or complete ranges.

### Analysis Packages
- [rgbif](https://docs.ropensci.org/rgbif/) - R interface to GBIF.
- [pygbif](https://pygbif.readthedocs.io/) - Python interface to GBIF.
- [rredlist](https://docs.ropensci.org/rredlist/) - R interface to IUCN Red List.
- [taxize](https://docs.ropensci.org/taxize/) - R taxonomic information toolkit.

## Frameworks & Standards

### Disclosure Frameworks
- [TNFD](https://tnfd.global/) - Taskforce on Nature-related Financial Disclosures.
- [SBTN](https://sciencebasedtargetsnetwork.org/) - Science Based Targets for Nature.
- [GRI Biodiversity Standard](https://www.globalreporting.org/standards/standards-development/topic-standard-project-for-biodiversity/) - Biodiversity reporting standard.

### Assessment Methodologies
- [IBAT](https://www.ibat-alliance.org/) - Integrated Biodiversity Assessment Tool.
- [STAR](https://www.iucn.org/resources/conservation-tool/species-threat-abatement-and-recovery-star-metric) - Species Threat Abatement and Recovery metric.
- [BII](https://www.nhm.ac.uk/our-science/data/predicts.html) - Biodiversity Intactness Index.
- [MSA](https://www.globio.info/) - Mean Species Abundance from GLOBIO.

### Data Standards
- [Darwin Core](https://dwc.tdwg.org/) - Standard for biodiversity data exchange.
- [ABCD](https://abcd.tdwg.org/) - Access to Biological Collection Data schema.
- [EML](https://eml.ecoinformatics.org/) - Ecological Metadata Language.
